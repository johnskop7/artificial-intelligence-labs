## Publish the package

Create a new empty repository with your chosen visibility and the name above. Extract the downloaded package and place its contents at the repository root, so `README.md`, `requirements.txt`, and `labs/` appear directly on the main page. Upload the individual folders/files, not the ZIP container.

If using Git, open a terminal inside the extracted `artificial-intelligence-labs` folder:

```bash
git init
git add .
git commit -m "Organize three Artificial Intelligence notebook labs"
git branch -M main
```

Then copy the exact remote URL and push instructions shown by your new GitHub repository. Set the description and topics in the repository's About settings. No live GitHub repository is created by this ZIP package.
