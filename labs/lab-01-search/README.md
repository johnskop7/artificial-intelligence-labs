# Lab 1: Maze search and adversarial planning

Open [maze_search.ipynb](maze_search.ipynb).

## Coverage

1. Generate random mazes with a guaranteed start-to-goal path and adjustable obstacle density.
2. Compare Dijkstra, greedy best-first, and A* configurations through the notebook's cost/heuristic interface.
3. Study path lengths and expanded-node counts across maze sizes.
4. Use alpha-beta adversarial search for an agent avoiding an A*-driven ghost; discuss the goal/safety heuristic and execution time.
5. Explore manually drawn mazes in the interactive bonus section.

The notebook includes the assignment, implementation, saved figures, and written commentary. Some bonus markdown retains the original template prompts; it is preserved as submitted.

## Inputs and execution

No external CSV files are required. Install the root requirements for local Jupyter execution. Run cells in order so maze, pathfinder, visualization, and agent definitions exist before the experiments.

The interactive bonus section imports `google.colab.output.eval_js` and displays a drawing interface. Use **Google Colab** for this section; it is not directly portable to ordinary Jupyter. Follow the drawing prompts, mark the start/goal, and finish the drawing before running the image-reading cell. Files such as `drawing.png` and `5.1.png` are generated by interaction, not missing dataset inputs. The default reader uses `/content/drawing.png`, matching the Colab workspace.

Avoid an unattended Run All through the drawing section: those cells require user interaction. Random maze generation and repeated experiments can be time-consuming and are not guaranteed to reproduce the saved outputs exactly.

See [the execution guide](../../docs/running-notebooks.md).
